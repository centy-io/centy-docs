# Marketplace

The [Centy Marketplace](https://marketplace.centy.io) lists all npm packages in the Centy ecosystem, sourced directly from the npm registry.

## What It Shows

The marketplace displays every package whose name starts with `centy-`, along with:

- **Package name** — links to the package page on npmjs.com
- **Description** — what the package does
- **Version** — the latest published version
- **Downloads** — monthly download count from npm

All listed packages are officially maintained by the Centy team.

## Accessing the Marketplace

Visit [marketplace.centy.io](https://marketplace.centy.io) in your browser. The page is statically generated and refreshed at build time, so download counts and versions reflect the state at the last deployment.
